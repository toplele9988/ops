# 广州外贸舞台灯光 AI 运营系统（代号：小乐 3.0）

本项目为面向Multi-Agent AI 运营协同工程，覆盖海外客户询盘捕获、多供应商出厂底价核算、实时外汇比价与自动化地道英文回盘。

## 核心架构
- **总指挥兼架构师**：Claude
- **工程执行劳工**：Codex (Astra / Sol)
- **前线感知与数据处理**：DeepSeek / Qwen 矩阵
- **业务核心逻辑**：出厂底价红线风控（¥260基准）、实时 FOB/DDP 计费模型、多品类灯具（频闪/光束/帕灯）工业级规格库
