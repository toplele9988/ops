## 系统要做什么

给两名团队成员提供同一个工作台：集中处理客户消息、资料、报价、订单及跟进，并通过系统管理页面配置渠道、账号和 AI。接入微信、阿里国际站、WhatsApp、Gmail、独立站，并为其他平台保留扩展接口。各渠道要分别完成历史与实时消息、附件、来源关联、知识处理、人工审核和发送回执的真实验收。

Qwen、DeepSeek 按任务辅助分类、检索和内容生成，Claude Code、Codex 参与开发。视频学习资料可以提出页面、交互与工程工具候选，须实际验证再使用。索引资料或生成摘要并不等于训练模型。
