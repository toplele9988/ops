# 会话名字

微信会话会合并本地已有的名字。刷新后会自动显示新名字。没有取得的名字会保留原有提示，不会凭聊天内容猜人名。

找群名时，先看通讯录备注，再看昵称。没有就找消息库各表中最新的有效群名，最后找供应商档案中该群的名称。空名字和“微信群 ·room”等占位文字会跳过。

找成员名时，先看通讯录，再看这个群里的成员昵称。不同群的昵称分开保存。私聊还会使用已有的联系人备注。显示前会去掉控制字符，最多保留 128 个字符，并把半角 `@` 换成全角。

WhatsApp 有联系人名或群名时直接显示。没有联系人名时，显示号码和按区号推断的国家。没有群名时，显示“WhatsApp 群”加末尾标识。群号和无法确认的联系人标识不会用于推断国家。

国家只按明确的国际电话号码推断。函数返回国家两位码和中文名；会话原有的 `country` 字段填两位码。共用区号只覆盖已经列明的地区，无法确定就留空。阿里没有明确号码时保留原来的国家字段。区号表依据 [国际电联公布的号码表](https://www.itu.int/dms_pub/itu-t/opb/sp/T-SP-E.164D-2016-PDF-E.pdf)，保存在代码中，不查询外部号码服务。

自动刷新需要由宿主接线。接线后，通讯录每六小时最多刷新一次。每个有消息的群，成员名单每 24 小时最多读取一次。每轮最多三个群。先登记本次尝试，再调用接口，重启也不会马上重复。失败会记录健康状态，并暂停十分钟。接口不重试。旧名字不会因为空回复、失败或迟到回复被删除。

微信通讯录页增加一行提示：有消息的会话还有几个没名字，以及“尚未刷新通讯录”“接口没返回群名”等原因。列表里的未采集群不会因此被接入。

只读核对：

```bash
env PYTHONPATH=src:/opt/imgw/wechat PYTHONDONTWRITEBYTECODE=1 \
  /opt/imgw/venv/bin/python -m console.names report
```

报告只输出各渠道的数量和原因计数。不会输出名字、群号、电话或消息。不会刷新通讯录、登记附件或生成媒体密钥。WhatsApp 只使用现有本机服务的两次读取：登录状态和最近会话列表。

微信统计全部角色的有效会话，包含私聊。WhatsApp 与运营台一样最多读取 500 条最近会话；达到上限会标明统计不完整。来源不可读或统计不完整时，命令返回非零退出码。所有输出值都是数字；中文键说明数字的含义。

接线、表结构及测试情况见 [交付说明](integration-names.md)。
