# 工作台界面开发记录

## 已应用的检查方法

根据视频中介绍的网站设计方法，参考 [Hallmark](https://github.com/Nutlope/hallmark) 的界面检查思路，优先检查可读性、键盘焦点、响应式布局、减少动态效果以及真实状态。这里借鉴的是检查方法：项目并未安装或运行该工具，也未引入其素材或代码。

当前公开的工作台样式包含窄屏布局断点、焦点样式和 `prefers-reduced-motion`；账号页面提供窄屏布局与表单反馈。会话页面区分已归档、不可用和尚未接入等状态，避免把占位按钮表现为可用功能。跟进备注的 HTTP 测试覆盖保存和并发冲突；账号测试使用临时账户及数据库。

## 后续验收

- 用真实业务接口分别核验成功、失败、加载和空状态；发送是否成功以渠道回执为准。
- 在手机、平板、桌面与键盘操作下检查布局、焦点和表单错误；对比度与减少动态效果需在实际浏览器验证。
- 使用虚构数据构建订单、客户、供应商和设置的交互原型，再连接实际数据；不得把原型画面视为功能完成。
- 如采用其他组件或动画库，先核对许可、依赖、加载性能和是否向外部传输数据，再决定是否引入。

公开仓库目前包含脱敏页面候选与测试，不是完整生产前端。测试和部署状态见项目 README。
