# 站点消息探针：匿名参考代码

此目录保留浏览器探针的拆分模块和合成测试，用于研究页面消息识别、事件归档、人工操作避让及命令回执。**它不是可安装的用户脚本，不要直接放入真实浏览器运行。** 目标域名、账户、存储键及请求地址已替换为示例，缺少历史采集主体、组装入口及生产配置；其中包含未来用于回填和发送的接口，并不表明真实发送已接通。

`manifest.json` 中的源码和匿名版本哈希用于追踪变更，不代表与现场已安装版本一致。需重新完成真实页面的身份、消息元数据、时间戳和来源验证后才能评估实时采集，不能仅凭服务运行或样例测试判断链路正常。

## 合成测试

```sh
python3 run-node-synthetic.py
```

该命令在临时目录使用 Node 模拟界面和网络接口，共 27 项检查；其中两组模拟不能替代真实浏览器的页面布局、可信事件和 Playwright 测试。运行器阻断常见 Node 网络接口，但不是操作系统级网络隔离，不应加入真实凭据或客户资料。原 `test-human-browser.js` 和 `test-pwa.js` 需要 Playwright 和浏览器，未在此次隔离检查中运行。
